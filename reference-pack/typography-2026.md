## D. 2026 Usage Rules (from trend evidence)
1. **Mono eyebrows everywhere:** small mono uppercase labels above serif/grotesque heroes (Speakeasy, Dirty Vine pattern). Use DM Mono, Space Mono, Geist Mono, JetBrains Mono.
2. **Serif renaissance is display-first:** serifs headline; grotesques still run body/UI. All-serif only for editorial/museumcore.
3. **Variable fonts are the default** (Fraunces, Bricolage, Sora, Unbounded): animate weight/optical-size on scroll for kinetic type (gate with `prefers-reduced-motion`).
4. **Sans-serif sameness is a liability** (Jaguar backlash; Wix trend 04). Every build gets ONE characterful face minimum.
5. **Max two families + one mono.** Load only used weights; `font-display: swap`; subset.
6. NEW-vs-corpus tally: **13 NEW pairings**, 7 IN-CSV/adjacent (sections A-B). Corpus remains valid; 2026 additions skew serif-display + mono-label + human-grotesque.
